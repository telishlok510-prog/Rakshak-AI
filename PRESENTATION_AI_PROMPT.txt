**Q1: How is Rakshak AI different from existing scam detection apps like Truecaller?**

A: "Truecaller only identifies callers. Rakshak AI is a comprehensive 5-pillar ecosystem:
- We analyze SMS, UPI, QR codes, screenshots, and voice calls
- We EXPLAIN why threats are dangerous in Gujarati/Hindi voice
- We provide interactive education with 12 lesson categories
- We offer 4 safe practice simulators including real scam call training
- We have district-wise community alerts covering all 33 Gujarat districts
- Most importantly: we're built specifically for rural, first-time digital users with low literacy."

---

**Q2: Does the project require internet connection and API keys?**

A: "Yes, internet is required for AI-powered detection through Google Gemini API. However, our PWA architecture allows educational modules, practice simulators, and some basic checks to work offline once loaded. This hybrid approach ensures core protection is always available while providing advanced AI analysis when connected."

---

**Q3: How do you ensure user privacy?**

A: "Absolute privacy by design:
- Zero login required - completely anonymous
- No sensitive data storage on servers
- Stateless architecture - no user database
- API keys are encrypted via environment variables
- Only sanitized text (not original content) is sent for analysis
- All user progress tracked locally in browser storage
- No data harvesting or selling"

---

**Q4: How accurate is your AI detection system?**

A: "We use AI-powered detection with Google Gemini combined with pattern recognition algorithms. The system has been tested on real Gujarat scam data with:
- <2 second analysis time
- Traffic-light risk scoring (Safe/Caution/Danger)
- Explainable results showing specific red flags
- Real Gujarati scam recordings for training validation
- All 36 quality checks passed during testing"

---

**Q5: Can this scale beyond Gujarat to other states?**

A: "Absolutely! Our architecture is state-agnostic:
- Adding new languages takes approximately 1 month
- District alert system is modular and extensible
- Already planned: Marathi, Tamil, Telugu, Bengali
- PWA deployment allows instant nationwide access
- No physical infrastructure needed
- API-based design enables easy integration with state-specific threat databases"

---

**Q6: What makes the '5-pillar' approach unique?**

A: "Most solutions focus on only ONE aspect:
- Banks provide awareness (no detection)
- Apps provide detection (no education)
- Nobody provides practice environments

Rakshak AI is the ONLY platform that combines:
1. PROTECT - Real-time threat detection
2. LEARN - Interactive financial literacy
3. PRACTICE - Safe sandbox training
4. REPORT - Community intelligence
5. CONNECT - Universal PWA accessibility

This holistic approach addresses the complete scam prevention lifecycle, not just one piece."
