## 🎬 Pro Tips for Realistic Audio

### 1. Add Background Sounds (Optional)
Use tools like Audacity to add subtle background noise:
- Light office ambience
- Phone line static
- Keyboard typing sounds

**Where to get sounds**: freesound.org, zapsplat.com

### 2. Use Different Voices for Dialogue
- **Scammer**: Use TTS voice
- **Victim responses**: You can either:
  - Use different TTS voice
  - Record yourself
  - Leave pauses (current implementation)

### 3. Adjust Speaking Rate
- Scammers often speak fast to create urgency
- Set speed to 1.1x-1.2x in TTS settings

### 4. Add Pauses
Most TTS tools support SSML tags:
```xml
<speak>
Hello <break time="2s"/> this is a pause
</speak>
```

### 5. File Format
- **Format**: MP3
- **Bitrate**: 128 kbps (smaller file size, still good quality)
- **Sample rate**: 44.1 kHz
